# Construction Maven

DoD Maven에서 영감을 받은 AI 기반 건설 리스크 관리 플랫폼.

## Architecture
6-Layer: Data Ingestion → Entity Extraction → Ontology → Risk Analysis → Knowledge Base → Presentation

## Key Capabilities
- Claude Vision API 기반 도면 OCR (P&ID, ISO, GA)
- Palantir Foundry 스타일 온톨로지
- [[FIDIC-Silver-Book]] 조항 지식 내장
- Google Sheets 양방향 동기화
