## n8n 코드노드 JavaScript 데이터 변환
**날짜:** 2024-11-09  
**링크:** [채팅 열기](https://claude.ai/chat/ceda76ea-4f21-4e69-ae35-2d60af1d6fe7)

n8n Code 노드에서 `Split Out` 노드로 데이터를 변환하는 방법.

**핵심 패턴:**
```javascript
// 배열을 개별 아이템으로 분할 (Split Out 대응)
const items = $input.first().json.items;
return items.map(item => ({ json: item }));

// 모든 입력 아이템 변환
const outputItems = $input.all().map(item => ({
    json: {
        ...item.json,
        fullName: `${item.json.firstName} ${item.json.lastName}`,
        timestamp: new Date().toISOString()
    }
}));
return outputItems;
```

**반환 형식:** 항상 `{ json: {...} }` 배열

## PPT 키워드 기반 자동 집계 / 3-Week Lookahead
**날짜:** 2026-02-04  
**링크 (1):** [채팅 열기](https://claude.ai/chat/a6f5013c-b284-4c93-8f39-6dd8ccf7b003)  
**링크 (2):** [채팅 열기](https://claude.ai/chat/5ac52251-273a-4f0c-8e2d-70986e381c64)

PPT의 작업 텍스트에서 키워드를 추출하고, Excel의 Description 컬럼에서 해당 키워드가 포함된 아이템을 자동 검색해 진행률을 표시하는 3-Week Lookahead 대시보드.

**핵심 로직:**
```javascript
// Multi-keyword AND matching (개선 버전)
const keywordArray = keyword.split(',').map(k => k.trim());
const normalizedKeys = keywordArray.map(k => k.toLowerCase());
const matchesAll = (desc) => {
    const lowerDesc = desc.toLowerCase();
    return normalizedKeys.every(k => lowerDesc.includes(k));
};
```

**사용 예:** `"Duct,Insulation"` → "Duct"와 "Insulation" 동시 포함 항목만 필터
