## 계산식 (EN 13480-3)

```
필요 두께: e = (P × Do) / (2 × f × z + P)

P = 설계압력 (MPa) = 16 × 1.1 = 17.6 bar = 1.76 MPa
Do = 외경 (mm)
f = 허용응력 (MPa)
z = 용접효율 (Seamless = 1.0)

최소두께: e_min = e + c (c = 부식여유)
```
